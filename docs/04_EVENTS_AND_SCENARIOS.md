# 04. 전체 이벤트 대사전 (사소한 로그 81종 + 주요 컷신 75종+ · v3.5)

> **설계 원칙 (v3.5 — 대규모 이벤트 풀 · 나이/경력 대사 분기 · 난이도 연동)**
> * 한 사람의 일생(약 200~240계절) 동안 지루한 반복 없이 매 계절 살아 숨 쉬는 이야기를 만나도록 **사소한 작업·일상 이벤트 81종(로그 전용)**과 **주요 컷신 이벤트 75종+(진행 정지 & 선택지)**을 구축하고, 최근 발동 계열 쿨다운(쉬움 6턴 / 어려움 3턴 / 지옥 2턴)으로 반복 도배를 방지한다.
> * 모든 주요 이벤트와 후일담은 **주인공의 나이(청년/중년 35~54/원로 55+) · 천하제일 우승 횟수(`tournamentWins`) · 명성 · 도장 규모**에 따라 대사와 호칭이 자연스럽게 분기된다.
> * 대규모 몬테카를로 테스트봇(330회 풀 일생: 5전략 150회 + 3난이도 180회)을 통해 출현율·생존율·경제 밸런스를 검증한다.

3. **어려움 / 지옥 전용 재해 · 진검 이벤트 (`disaster_nature`, `disaster_plague`, `realduel_assassin`, `breaker_fight_real`)**: 천재지변(대홍수·대흉년·지진), 고을 대역병 재창궐, 살수단 진검 야습, 도장깨기의 진검결투 격상이 추가되어 생존 긴장감을 극대화한다.

### B.5 가족 · 동반 노화 라이벌 · 히든 판타지 충격파 (10종)
* **동반 노화 라이벌 4막**: 1막 첫 만남 → 2막 중년 문파전 → 3막 노년 제자 대리전 → 4막 눈 내리는 황혼 밤 최후의 한 합 or 술잔.
* **가족 3막**: 봄날의 인연과 혼례 → 자녀 출생 → 55세 후계자 지명의 밤(친자식 vs 천재 수제자).
* **히든 판타지 충격파 5종**: 허공의 불꽃 첫 목격 → 관군·퇴마사 요괴 도장 토벌전 → 서양 선교사의 경악과 유럽 밀서 → 황제/쇼군 국사 비밀 초빙 → 금기 초식 주화입마의 밤.

### B.6 타 문파 사건 · 문하생 말썽 · 반란 (v3.8, 15종 + 기존 이벤트 개입 6곳)

코드: 고르는 쪽 `src/data/sectEvents.ts`, 처리하는 쪽 `src/engine/sectLogic.ts`. 역사 이벤트 다음, 랜덤 풀 앞에서 판정한다. 발생 확률과 최소 간격은 난이도 설정(`troubleEventRate`, `sectEventRate`, `dramaGap`)을 따른다.

| ID | 조건 | 선택지 |
| :--- | :--- | :--- |
| `trouble_brawl` | 다혈질 제자 | 사과하고 치료비 / 사과 거절 / 엄벌 |
