# 04. 전체 이벤트 대사전 (사소한 로그 75종 + 주요 컷신 70종 = 총 145종)

> **설계 원칙 (v3.1 — 대규모 이벤트 풀 & 데이터 기반 밸런스)**
> * 한 사람의 일생(약 200~240계절) 동안 지루한 반복 없이 매 계절 살아 숨 쉬는 이야기를 만나도록 **사소한 작업·일상 이벤트 75종(로그 전용)**과 **주요 컷신 이벤트 70종(진행 정지 & 선택지)**으로 총 145종을 구축한다.
> * 모든 주요 이벤트는 **5축 세평(`인덕/살기/상무/구도/이단`)**과 연동되며, 대규모 몬테카를로 테스트봇(150회 풀 일생)을 통해 출현율·중복률·보상 밸런스를 지속 검증한다.

* **히든 판타지 충격파 5종**: 허공의 불꽃 첫 목격 → 관군·퇴마사 요괴 도장 토벌전 → 서양 선교사의 경악과 유럽 밀서 → 황제/쇼군 국사 비밀 초빙 → 금기 초식 주화입마의 밤.
