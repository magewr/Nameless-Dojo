# 08. 32비트 도트 시뮬레이션 UI/UX · 화면 흐름도 및 연출 가이드 (v3.0)

> **아트 & UX 핵심 원칙 (슬롭 제로 · 아이콘 우선 · 텍스트 70% 다이어트)**
> * **비주얼 화풍**: 2000년대 32비트 픽셀아트(《옥토패스》·《스타듀 밸리》·《월화의 검사 2》 감성) + **1750년 조선(망건·철릭)·청(변발·마괘)·일본(촌마게·기모노) 시대 고증**.
> * **UI 프레임 통일**: 타이틀부터 엔딩까지 **다크 목재·황금 보더 2000년대 RPG 프레임(`rpg-window`)**으로 100% 통일.
> * **아이콘 중심 초슬림 레이아웃**: 장황한 문단 설명을 걷어내고 **`♥ 96` · `🪙 120` · `★ 45` · `⚔ 24` · `💧 10`** 아이콘+수치 뱃지 위주로 배치해 데스크탑과 모바일 어디서도 글자 밀림·잘림 0%.

## 3. 모바일 (`390×844`) 반응형 설계
* **상단 HUD**: 1줄 아이콘+숫자 압축(`♥96 🪙20 ★10`), 줄바꿈/밀림 원천 차단.
* **중앙 디오라마**: 화면 상단 42~48% 영역에 도장 핵심 영역이 선명하게 표시되며, 계절 진행 시 미니 피드가 디오라마 하단에 반투명 2줄 토스트로 자연스럽게 중첩.
* **하단 계획 보드**: 3×3 아이콘 타일 그리드로 엄지손가락 하나로 가볍게 1~4개 작업 토글 후 대형 `[계절 시작 ▶]` 버튼 탭!
