# 08. 32비트 도트 UI/UX · 8프레임 VFX · 입체 사운드 및 화면 흐름도 가이드 (v3.5)

> **아트 & UX 핵심 원칙 (슬롭 제로 · 32비트 픽셀 스프라이트 VFX · 입체 사운드 · 모바일 최적화)**
> * **비주얼 화풍**: 2000년대 32비트 픽셀아트(《옥토패스》·《스타듀 밸리》·《월화의 검사 2》·《사무라이 쇼다운》 감성) + **1750년 조선(망건·갓·철릭·한복)·청(변발·마괘)·일본(촌마게·기모노·하카마) 시대 고증**.

## 3. 모바일 (`390×844`) 반응형 설계

## 4. 32비트 픽셀 VFX 스프라이트 & 입체 사운드 명세 (v3.5)

### 4.1 32비트 픽셀아트 VFX 시트 체계 (`public/assets/`, `src/pixel/katanaVfxRenderer.ts`)
모든 VFX 시트는 순수 검정(`#000000`) 배경 → 광원 알파 변환 + 안쪽 2px 크롭 + 가산합성(`lighter`) + 인접 프레임 크로스페이드 보간(`drawSmoothVfxSprite`)으로 60fps처럼 매끄럽게 재생된다.
* **전용 8프레임(4×2) 초고속 애니메이션 6종 (`20~30 FPS`)**:
  * `grid_vfx_slash_8f.jpg` (초승달 대참격 8프레임)
  * `grid_vfx_fire_8f.jpg` (화염 기둥·폭발 8프레임)
  * `grid_vfx_lightning_8f.jpg` (천뢰 낙뢰·분기 번개 8프레임)
  * `grid_vfx_ice_8f.jpg` (빙정 융기·파쇄 8프레임)
  * `grid_vfx_shadow_8f.jpg` (동양 마법진·암영 소용돌이 8프레임)
  * `grid_vfx_qi_8f.jpg` (태극 링·황금 승룡 기둥·순금 폭발 8프레임)
* **검격·간파·체세붕괴·지면파쇄 (`grid_vfx_slash_parry_8f.jpg`)**: 청백/대참격/진홍일섬/맨손 권풍, 황금 4방향 간파 별빛, 연환 충돌 폭발, 체세 붕괴 방패 파편, 지면 균열 암석 폭발.
* **암전 11연참 단획 (`grid_vfx_katana_strokes_4x2.jpg` Row 0)**: 청백·진홍·황금·은백 4종 면도날 단획이 48→34ms 가속 간격으로 36ms 고속 마스크 와이프되며 하나씩 화면을 가르고, 납도 정적("찰칵!") 후 일제 팽창 파열.
* **KO 단칼 일섬 한 획 (`vfx_ko_onestroke_straight.jpg`)**: 그리드 없는 16:9 이음새 0% 통짜 면도날 일섬 스프라이트가 임팩트 프리즈(85ms) 직후 적을 관통하며 화면 전체를 단 한 획으로 양분한 뒤 면도날 실선으로 수축 소멸.

### 4.2 입체 멀티레이어 Web Audio 사운드 엔진 (`src/engine/sound.ts`)
* **마스터 버스**: `DynamicsCompressorNode` + 프로시저럴 목조 도장 공간 `ConvolverNode` 리버브(0.48초) + `StereoPannerNode`(전투 X좌표 기반 좌/우 위치감) + 소프트 새츄레이션.
* **전투 다층 효과음**: 발도 스르릉(`playUnsheathe`), 도검 파공 vs 맨손 권풍(`playSlash`), 서브베이스+크랙+배음 타격(`playHit`), 5중 비정수 강철 공명 연환 간파(`playParry`), 5원소 시그니처(`playMagic`), 체세 붕괴 3연타 크랙(`playGuardBreak`), 타임 슬로우(`playTimeSlow`), 납도 대폭발(`playDarkSlashFinish`), KO 동양 징·대북(`playKoFinisher`), 동양 5음계 팡파르(`playLevelUp`).

### 4.3 전용 VFX · 입체 사운드 테스트관 (`?vfx-demo=1`)
* `src/components/VfxAudioShowcase.tsx`: 본 게임 세이브에 영향 없이 모든 8프레임 픽셀 VFX 10종, 11연참 암전, 단칼 KO 일섬, 16종 단독 사운드보드(좌/중앙/우 스테레오), 1.0x / 0.4x 슬로우 감상, 3국×2성별×3연령대×도검/맨손 캐릭터 전환을 실시간 검증할 수 있다.

### 4.4 영구 도전과제 (27종) & 난이도 UI
