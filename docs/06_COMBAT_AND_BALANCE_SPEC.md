## 1. 계절 계획 (`1/n` 배분) 시뮬레이션 명세

### 1.1 계절 준비 → 자동 진행 → 계절 결산 흐름
1. **계절 준비 (Planning Phase)**:
   * 도장 정비(시설 증축, 무기 장착/강화, 초식 덱 구성, 제자 역할·전수)는 시간 소모 없이 언제든 세팅.
   * 이번 계절에 수행할 작업을 **1개 ~ 최대 4개**까지 자유롭게 선택.
2. **효율 배분 공식 (`1/n` 규칙)**:
   * 선택한 작업 개수가 `n`개일 때, **각 작업의 기본 진행량·경험치·수익 = `단일 집중(100%) 기준치 × (1 / n)`**.
   * **1개 집중 (`100%`)**: 한 분야(예: `횡베기` 연마 또는 이계 금서 해독)에 한 계절을 통째로 쏟아 폭발적 성장.
   * **2개 병행 (`각 50%`)**: 수련과 생계, 또는 연마와 해독을 균형 있게 진행.
   * **3~4개 다중 (`각 33% / 25%`)**: 개별 속도는 느려지지만 여러 목표가 동시에 진척되고, **작업마다 독립적인 사소한 미니 이벤트**가 발생해 다양한 기연과 보너스를 노릴 수 있다.
   * *(중상/황혼기 건강 35 미만 시)*: 무리한 병행 제한 → 최대 선택 가능 작업 수 `2개`로 제한, 전체 효율 `× 0.75`.
3. **계절 자동 진행 (Execution Phase — 초순 · 중순 · 하순)**:
   * `[계절 시작 ▶]` 클릭 시 3단계(`초순 → 중순 → 하순`) 타임라인이 흐른다 (`1x 감상 / 2x 빠름 / 즉시 완료` 배속 지원).
   * 도장 디오라마에서 주인공이 선택된 작업 장소(`목인장 / 장서각 / 대장간 / 약방 / 대문`)를 순회하며 4프레임 스프라이트 애니메이션을 수행하고, 머리 위로 플로팅 수치가 뜬다.
   * **사소한 이벤트 (Minor Events)**: 각 작업 틱마다 확률적으로 발생 → 진행을 끊지 않고 우측 미니 피드 & 로그에 기록.
   * **주요 이벤트 (Major Events)**: 중순 또는 하순에 도장깨기·만물객·라이벌·역사 사건·가족·3·6·9 각인이 발생하면 **타임라인이 일시 정지** → 32비트 컷신 & 플레이어 입력(또는 자동전투 관전) 처리 후 남은 일정 재개!
4. **계절 결산 (Summary Card)**:
   * 계절 종료 시 월사금/유지비 수지, 스탯 변화, 초식 성장, 제자 변이/열화, 건강·노화 결과를 한 장의 간결한 결산 카드로 요약.

## 2. 완전 자동전투 시뮬레이션 명세 (Full Auto-Battle)

### 2.1 전투 전 세팅 (플레이어 전략 영역)
* **출전자 선택**: 도장주 직접 출전 또는 문하생·친자녀 대리전.
* **초식 덱 구성**: 액티브 초식 슬롯(기본 4칸, `INS 50+` 5칸) + 운기 심법 패시브 슬롯(기본 1칸, `QI 50+` 2칸) + 장착 무기.
* **전투 방침 (Tactics — 3택 1)**:
  * `적극 공세`: 공격 빈도 +20%, 선제 접근 성향, 방어 확률 소폭↓.
  * `균형`: 거리·상성·기력에 맞춘 표준 AI 판단.
  * `간파 수비`: **저스트 간파(看破) 시도 확률 +15%**, 카운터 반격 우선 (노년기·태극/방어 빌드에 최적!).

### 2.2 자동전투 리소스 및 AI 판정 공식
* **최대 HP** = `110 + VIT × 6`
* **최대 기력/마력 (QI)** = `45 + WIL × 2 + QI × 1.5` (초당 회복: `7 + WIL × 0.16`)
* **최대 체세 (Posture)** = `80 + VIT × 2 + STR × 1.5` (0이 되면 1.8초 그로기, 받는 피해 1.5배)
* **자동 간파(看破) 발동 확률** (황색 공격 피격 직전):
  * `P_parry = clamp(0.08 + INS × 0.0055 + 방침보정 + 심안각성(+0.22), 0.08, 0.72)`
  * 청년(`INS 20`): 약 `19%` / 노년(`INS 95` + 간파 수비): **약 `70%`!** — 늙은 고수가 젊은 상대의 맹공을 연달아 **「看破」**로 흘려내는 장관이 자연스럽게 연출된다!
* **자동 적색 회피 확률** (적색 강공·마법 피격 직전):
  * `P_dodge = clamp(0.10 + AGI × 0.0055 + 보법초식보정(+0.15) - 다리절음(0.18), 0.05, 0.68)`
* **동작 속도 배율**: `1.35 - (AGI × 0.006)` *(청년 `0.84배` 고속 회전 vs 노년 `1.17배` 묵직한 한 방)*.
* **최종 피해량 공식**:
  ```text
  기본 피해 = 초식 위력 × (1 + 연마 경지 × 0.13) × 무기 궁합(0.8 ~ 1.35)
  스탯 보정 = 물리(STR×0.75 + 무기×0.85) / 찌르기(AGI×0.75 + 무기×0.85) / 마법·강기(WIL×0.65 + QI×1.05 + 무기×0.6)
  최종 피해 = (기본 피해 + 스탯 보정) × 각인 배율 × 간파/그로기 배율(1.55x)
  ```
* **관전 편의 기능**: `1x (일반 감상)` / `2x (쾌속 관전)` / `결과 즉시 보기` 버튼 상시 제공.

## 3. 노화(Aging) 커브 · 스탯 상한 · 수명 상한

| 연령 구간 | 신체 상한 (STR/AGI/VIT) | 정신 상한 (WIL/INS/QI) | 최대 건강 상한 | 자동전투 관전 특징 |
| :--- | :---: | :---: | :---: | :--- |
| **15 ~ 34세 (청년)** | **95** | 75 | 100 | 고속 연타 & 높은 회피율의 속도전 |
| **35 ~ 49세 (완성)** | **95** | 75 | 100 | 공수 균형 전성기 |
| **50 ~ 64세 (노년)** | **70** *(하락)* | **100** *(돌파!)* | 100 → 78 | 느리지만 압도적 `INS` **연속 간파 + 오의 일격** |
| **65 ~ 82세 (황혼)** | **50** *(하락)* | **100** | 78 → 0 *(천수)* | 양생법·약방 Lv.4로 수명 연장 가능, 후계자 대리전 활약 |

## 4. 연마 경지(Lv.1~10) & 조합 레벨 계승 공식
* **경지별 필요 EXP**: `Lv.1→2(100)`, `2→3(150, 1차 각인)`, `3→4(200)`, `4→5(250, 금서 해독 자격)`, `5→6(350, 2차 각인)`, `6→7(450)`, `7→8(550, 무검승유검)`, `8→9(650, 3차 각인)`, `9→10(800, 신기)`.
* **조합 레벨 계승**: `floor((재료A_Lv + 재료B_Lv) × 0.4)` *(최소 Lv.1 ~ 최대 Lv.5, Lv.3+ 탄생 시 즉시 1차 각인)*.

## 5. 도장 시설 경제 · 5축 세평 · 영구 장애 각성

* **초기 폐허 유지비 면제**: Lv.1(폐허) 시설 6개는 유지비 `0`. Lv.2 이상 증축한 단계부터 `(총레벨 - 6) × 8 + 생존 제자 × 4` 적용.
* **월사금 수익**: `제자별 월사금 × (1 + min(3.0, sqrt(명성) × 0.12))` — 후반 무한 인플레이션 방지.
* **5축 세평 (`인덕 / 살기 / 상무 / 구도 / 이단`)**: 행적 누적에 따라 단일 15종 + 복합 6종(`구세신선문`, `재앙의 마도`, `성현무림`, `혈금용병단`, `진리의 마도탑`, `태평천하 표국`) 자동 부여.
* **영구 장애 & 극복 각성**:
  * `외팔` → 진검 3승 → **【외팔 검성】** (한손 도검 선딜 -25%, 피해 +35%)
  * `실명` → 자동 간파 누적 8회 → **【심안의 맹인 검객】** (`INS +25`, 자동 간파 확률 +22%)
  * `다리 절음` → 방어/카운터 5승 → **【부동명왕】** (받는 피해 -30%, 체세 소모 0)
* **초반 4계절(1750년) 온보딩 흐름**:
  * **1계절 (봄)**: 프롤로그 컷신 종료 → 첫 계절 계획(`횡베기 연마` + `호위·생계` 등) 선택 안내 → `[계절 시작 ▶]` 체험.
  * **2계절 (여름)**: 왈패 두목 도장 입장 컷신 → **첫 완전 자동전투(관전 & 초식 덱 이해)**.
  * **3계절 (가을)**: 1호 문하생 입문 컷신 → 제자 자율 수련 시작.
  * **4계절 (겨울)**: 선대 빚 정산 + **비밀 상인 「만물객」 첫 방문** → 첫 서적 구매 & 조합 개방!
