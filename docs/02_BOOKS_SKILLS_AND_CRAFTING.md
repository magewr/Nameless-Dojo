# 02. 서적(비급) · 무술 스킬 · 조합식 및 연마 각인 대사전

> **설계 철학**
> * 초기 무술은 철저히 보잘것없는 2개(`횡베기`, `종베기`)뿐이다.
> * 동아시아 3국과 18세기 유럽의 **실존 무술 교본**을 고증하여 서적의 리얼리티를 극대화하고, 그 틈에 **2% 극악 확률의 판타지 금서 7권**을 숨겨 대비감을 극대화한다.
> * 모든 무술은 **태그 기반 호환성 + 시그니처 레시피**로 조합되며, 3·6·9단계 **연마 각인**과 **금기 초식**, **전수 열화/변이**를 통해 매 판 전혀 다른 무술 계통도가 완성된다.

### 1.2 원형 초식 3·6·9단계 연마 각인 (외길 극한 빌드 핵심)

#### `횡베기` 전용 각인 분기
* **3단계 (숙달)** — 택 1:
  1. `신속 발도`: 선딜 -30%, 쿨타임 -20% *(초고속 견제기화)*
  2. `파갑 호선`: 적 방어/체세 피해 +50% *(가드 브레이크 특화)*
  3. `넓은 궤적`: 적의 보법 회피 판정을 무시하고 명중
* **6단계 (화경)** — 택 1:
  1. `검풍 발현`: 사거리가 중거리로 확장, 바람의 검기 투사
  2. `연환 기세`: 명중 시 다른 장착 초식 쿨타임 -1000ms
  3. `간파 일섬`: 저스트 패링(간파) 직후 사용 시 피해 2.2배
* **9단계 (입신 — 오의 각성)** — 택 1:
  1. `【무형일선(無形一線)】`: 시전 전조 제거, 적이 반응하기 전에 베어 넘김
  2. `【단산참(斷山斬)】`: 체력 30% 이하의 일반/보스 적 처형 판정
  3. `【만화귀일(萬化歸一)】`: 적의 모든 속성 저항 및 방어 무시

#### `종베기` 전용 각인 분기
* **3단계 (숙달)** — 택 1:
  1. `천근추(千斤墜)`: 피해량 +35%, 전조가 **적색(방어 불가)**으로 승격
  2. `연속 내려치기`: 명중 시 40% 위력의 추가타 1회 자동 발동
  3. `무기 쳐내기`: 적의 황색 공격 전조와 부딪히면 적 초식을 강제 차단
* **6단계 (화경)** — 택 1:
  1. `지열참(地裂斬)`: 땅을 갈라 충격파 생성, 중거리 적에게 경직(0.8초) 부여
  2. `강기 응축`: QI 15를 추가 소모해 피해량 +70%
  3. `불굴의 일격`: 시전 중 피격당해도 끊기지 않음(슈퍼아머)
* **9단계 (입신 — 오의 각성)** — 택 1:
  1. `【양단참(兩斷斬)】`: 적의 무기 내구도 파괴 및 체세 즉시 붕괴
  2. `【낙성격(落星擊)】`: 공중 도약 후 낙하 참격, 광범위 치명타
  3. `【무검승유검】`: 무기 없이 맨손이나 나뭇가지로도 100% 위력 발휘

> *(모든 창작 초식 역시 3·6·9단계 도달 시 자신의 형태·속성 태그 풀에서 3개의 각인 후보가 제시되어 매번 다르게 진화한다.)*

## 3. 무술 조합식 (Crafting Matrix) 및 시그니처 레시피

### 3.1 태그 기반 개연성 조합 엔진 규칙
조합 `[A] + [B]` 시도 시 아래 3단계로 판정한다.
1. **시그니처 레시피 일치**: 아래 정의된 40종의 특별 조합에 해당하면 고유 명칭·특수 효과로 완성.
2. **일반 태그 호환**: 시그니처에 없더라도 아래 호환 규칙을 만족하면 **동적 명명 엔진(`속성 접두어 + 형태 접미어`)**으로 새 초식 창조.
   * `[공격 형태(베기/찌르기/타격)] + [원소 마법/강기]` → **가능** (속성 부여 무기 초식)
   * `[공격 형태] + [보법/가속]` → **가능** (돌진/선제 고속 공격기)
   * `[공격 형태] + [다른 공격 형태 (동일/호환 무기)]` → **가능** (연환 콤보 초식)
   * `[방어/흘리기] + [잡기 또는 찌르기]` → **가능** (카운터 전용 초식)
   * `[심법/보조] + [원소 마법]` → **가능** (광역/지속 버프 오라)
3. **개연성 충돌 & 금기 초식 예외**:
   * 예: `[잡기] + [원거리 투사 마법]`, `[화염] + [빙결]`, `[무기군 완전 불일치(창 + 맨손 잡기)]` → 기본 **조합 실패**.
   * 단, 주인공의 **`통찰(INS) >= 75`** 이상일 때 *"이단적 발상을 밀어붙이시겠습니까? (금기 초식 탄생 위험)"* 선택지가 열리며, 성공 시 막강한 위력 대신 **체력/수명 반동 리스크**를 지닌 **【금기 초식】**이 탄생한다!
4. **조합 시 연마도 계승 & 계절 계획(`1/n`) 진행 규칙**:
   * 신규 창작 초식은 재료의 숙련도를 이어받아 `floor((재료A_Lv + 재료B_Lv) × 0.4)` *(최소 Lv.1 ~ 최대 Lv.5)*로 시작하며, Lv.3 이상 탄생 시 즉시 1차 각인을 고른다.
   * **계절 계획 진행도 (`1/n`)**:
     * `무술 조합`은 진행도 `100%` 도달 시 완성된다 *(1개 단독 집중 시 1계절 완성, 2개 병행 시 2계절, 4개 병행 시 4계절)*.
     * `서적 해독`은 일반 서적(`0%` — 구매 즉시 습득), 희귀/서양 서적(`100%`), 전설 비급(`180%`), 이계 금서(`260%`)의 진행도를 가지며, 장서각 레벨과 겨울 계절에 진행 속도가 가속된다.
   * `[심법]` 태그 기술은 자동전투 액티브 슬롯(5칸)을 차지하지 않고, 별도의 **운기 심법 슬롯(패시브 1~2칸)**에 장착한다.

## 4. 제자 전수 시 열화(劣化) 및 변이(變異) 규칙

주인공이 창시한 초식을 제자·자녀에게 전수할 때, 제자의 스탯과 재능 태그에 따라 3가지 결과가 발생한다.

1. **완벽 계승 (Perfect Succession)**
   * *조건*: 제자의 해당 초식 핵심 스탯(`QI`, `INS`, 주 스탯)이 요구치의 100% 이상.
   * *결과*: 초식의 이름, 위력, 각인 특성까지 온전히 계승.
2. **계승 열화 (Degradation)**
   * *조건*: 제자의 스탯이 요구치의 60~99% 수준(특히 마법·강기 초식에서 `QI` 부족).
   * *결과*: 초자연 속성이나 핵심 효과가 탈락하고 하위 호환 초식으로 변질.
   * *예시*:
     * `홍련횡단참(화염 검기)` → **`열풍횡베기`** *(화염 소실, 뜨거운 바람만 이는 일반 검술)*
     * `무형일선(전조 없는 횡베기)` → **`속전횡베기`** *(단순히 조금 빠른 횡베기)*
     * `사량발천근(완벽 카운터)` → **`어설픈 흘리기`** *(피해 경감만 남음)*
   * *사후 타임라인 영향*: 열화된 초식이 본가에 남으면 100년 뒤 *"원래는 화려한 검무(춤)였다"*로 왜곡되어 전해진다!
3. **계승 변이 / 청출어람 (Mutation)**
   * *조건*: 제자가 `천재` 또는 특정 속성/무기 재능 태그를 보유하고, 스승 초식의 숙련도를 6단계(화경) 이상 달성 시 20% 확률로 발생.
   * *결과*: 제자가 스승의 초식을 자기 적성에 맞게 재창조해 보고하는 특별 이벤트 발동!
   * *예시*:
     * `홍련횡단참` + 빙결 적성 제자 → **【설화횡단참(雪花橫斷斬)】** *(화염 대신 서리 검기)*
     * `십자참` + 창술 천재 제자 → **【십자비룡창】** *(검술 원리를 창술로 이식)*
     * `금강정권` + 복싱 호기심 제자 → **【폭풍연타권】** *(단발 정권을 초고속 연타로 개조)*
   * 플레이어는 제자의 변이 초식을 **유파 정식 초식으로 채택(유파 계통도 확장 + 제자 충성도↑)**하거나, **사문(邪門)이라며 금지(제자 불만·분파 씨앗)**할 수 있다.

## 5. 태그별 범용 3·6·9단계 연마 각인 풀 (Pool)

`횡베기`·`종베기` 외의 모든 서적 기술 40종과 플레이어가 창시한 모든 조합 초식은 **Lv.3(숙달) · Lv.6(화경) · Lv.9(입신)** 도달 시 자신의 `[형태]` 및 `[속성]` 태그에 해당하는 아래 풀에서 무작위 3개 후보를 뽑아 1개를 영구 각인한다.

### 5.1 형태(Form) 태그별 범용 각인 풀

| **찌르기 (Thrust)** | `급소 조준`(치명타 +25%) / `최장 신장`(사거리 +1단계) / `초속 돌진`(선딜 -30%) | `관통 일점`(방어력 50% 무시) / `전조 차단`(적색 전조 차단 시 기절 1s) / `연속 찌르기`(2회 타격) | `천광관통`(모든 방어·실드 무시) / `심장 일격`(치명타 배율 2.5배) / `무한 연자`(치명타 시 쿨 초기화) |

| **방어 (Parry)** | `견고한 자세`(체세 소모 -40%) / `넓은 간파`(간파 창 +60ms) | `반격 일섬`(간파 시 자동 반격 피해) / `기력 순환`(간파 시 QI +35) | `절대 간파`(적색 강공까지 1회 패링 가능!) / `무도 제압`(간파 시 적 무기 3초 무력화) |

| **심법 (Aura)** | `깊은 호흡`(QI 회복 +25%) / `강인한 혈맥`(최대 HP +15%) | `전투 집중`(모든 초식 쿨타임 -12%) / `기운 보호`(피격 시 피해 -15%) | `천인합일`(모든 스탯 +15%) / `불로 양생`(노화 건강 감소 -50%) |

### 5.2 원소·속성(Element) 태그 전용 보너스 각인 풀
원소/초자연 태그가 붙은 초식은 3·6·9단계에서 아래 속성 각인도 함께 후보로 등장한다.
* **화염**: `업화 연소`(화상 피해 2배) / `폭염 폭발`(화상 3중첩 시 대폭발) / `재의 장막`(피격 적 방어력 -30%)
* **빙결**: `만년 서리`(적 선딜/쿨 +35% 둔화) / `절대 동결`(빙결 지속 +1.2초) / `쇄빙참`(동결된 적에게 피해 2.2배)
* **뇌전**: `고압 감전`(적 쿨타임 정지 1.5초) / `신경 가속`(시전자 3초간 선딜 -25%) / `연쇄 낙뢰`(명중 시 추가 번개 낙하)
* **질풍**: `초음속`(선딜·후딜 -35%) / `진공 검압`(사거리 +1단계 & 적 밀쳐냄)
* **강기**: `파마(破魔)`(적 버프·실드 즉시 해제) / `내공 증폭`(QI 10 추가 소모 시 피해 +50%)
* **환영/독**: `맹독 중첩`(중독 최대 5중첩, 회복 차단) / `환영 교란`(적 AI가 2초간 헛방 유도)

## 6. 동적 초식 자동 작명 사전 (시그니처 외 자유 조합 엔진)

시그니처 40종에 해당하지 않지만 태그 호환이 성립하는 모든 자유 조합은 아래 3단 조합 엔진으로 자연스러운 무협/동양식 이름을 자동 제안한다. *(이후 플레이어가 언제든 직접 개명 가능)*

### 6.1 작명 공식
* **기본 구조**: `[속성/기세 접두어]` + `[동작/계통 중심어]` + `[형태 접미어]`
